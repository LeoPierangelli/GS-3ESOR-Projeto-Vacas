# Ordenha Monitorada

Projeto da Global Solution 2026/2 (FIAP, CitizenTech). É um sistema que avisa o pequeno produtor de leite quando uma vaca dá sinal de mastite, de queda de produção ou de leite em carência, a partir de dois sensores na ordenha: um de volume e um de condutividade.

- **Cidadão beneficiado:** o pequeno produtor de leite, com rebanho pequeno e ordenha simples.
- **ODS:** 2 (Fome zero e agricultura sustentável) e 3 (Saúde e bem-estar).
